# Untold Engine Trademark Policy

The name "Untold Engine" and the Untold Engine logo are trademarks of Untold Engine Studios.

This trademark policy governs the use of these marks.

## Allowed Uses

You may use the Untold Engine name to:

- Describe the software
- Reference the open source project
- Create tutorials, documentation, or educational materials

Examples:

"Built with Untold Engine"
"Plugin for Untold Engine"

## Restricted Uses

You may NOT use the Untold Engine name:

- In the name of a competing engine
- In a way that suggests official endorsement
- In product names without permission

Examples of prohibited usage:

Untold Engine Pro  
Untold Engine XR Platform  
Official Untold Engine Toolkit

## Forks

Forks of the project must:

- Remove the "Untold Engine" name
- Replace branding and logos

Example:

Allowed:
"Fork of the Untold Engine project"

Not allowed:
"Untold Engine Enhanced"

## Logo Usage

The Untold Engine logo may not be used without permission from Untold Engine Studios.
